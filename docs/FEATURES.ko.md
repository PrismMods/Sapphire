# 기능

Sapphire는 **A Dance of Fire and Ice**용 에디터 스위트 모드입니다 (UnityModManager).
게임 내장 에디터 위에 현대적인 채보/VFX 제작과 편집 환경을 마련합니다.

이 문서는 Sapphire가 하는 일을 정리한 요약본입니다. 기능이 추가될 때마다 갱신됩니다.

---

## 시작하기

- **마스터 스위치** — 우측 상단의 전원 버튼이 스위트 전체를 켜고 끕니다. 끄면 바닐라 에디터와 동일합니다.
- **설정** — `Ctrl+E`로 설정 패널을 엽니다 (스킨 강조색, 토글, 모듈 옵션).
- **매뉴얼** — 활성 도구 옆의 `?` 버튼이 에디터 내 사용 설명서를 엽니다.

## 툴바 도구

Adobe 스타일 툴바가 기존 이벤트 팔레트를 대체합니다. 아무것도 선택하지 않았을 때 숫자 키
`1`–`0`이 현재 선택된 카테고리의 도구를 고릅니다. 각 셀은 마우스오버 시 툴팁이 보입니다.

| 도구 | 기능 |
|---|---|
| **원형 경로** | 호/원/별을 만듭니다. |
| **자유 각도** | 타일을 드래그해 자유롭게 회전하며(**Left-Alt**를 누르거나 도구를 활성화), 우클릭은 타일 메뉴용으로 남겨둡니다. |
| **동타** | 타일을 박자를 유지한 채 동타로 변환하며(단일 클릭 또는 다중 선택), 미드스핀/소용돌이 구성과 리튠을 지원합니다. |
| **카메라 경로** | 화면 위 FreeCamera 경로 오버레이로, 키프레임 클릭 검사와 ▶ 미리보기, 박자 간격을 둔 전체 재생을 제공합니다. |
| **드르륵** | 타일을 드르륵으로 대체하며, 360°를 N개의 키에 균등하게 나눕니다 (최소 4개). |
| **VFX 미리보기** | 모든 UI(게임 UI 포함)를 숨겨 이펙트를 미리보는 VFX 전용 모드로, 플레이 모드까지 유지되며 ESC로 종료합니다. |
| **인스펙터** | 스포이드로 좌클릭 시 타일의 이벤트를 캡처하고 우클릭 시 타일에 붙여넣으며, 복사 패널은 붙여넣기 필터로도 동작합니다. |
| **빠른 차팅 (Q)** | 빠른 채보 작성 모드를 토글합니다 (아래 참조). |
| **도형 라이브러리** | 재사용 가능한 도형의 도킹형 팔레트입니다 (아래 참조). |
| **Hz 도구 (♪)** | 주파수로 차팅하고 음을 고릅니다 (아래 참조). |

기타 편의 도구:

- **선택적 복사 + 반전** 패널 (다중 선택, 우측 상단) — 여러 타일을 복사하고 지오메트리를 반전합니다.
- **필터 브라우저** — 게임의 약 300개 항목짜리 `SetFilterAdvanced` 드롭다운을 검색 가능한
  카테고리별 브라우저로 만듭니다 (칩이 게임 이벤트 패널에 붙어 다닙니다).
- **이벤트 프리셋** — (인스펙터로) 이벤트 묶음을 이름 붙여 저장하고 다시 찍어 붙여넣습니다.

## 타임라인 & 카메라

하단에 도킹된 **이벤트 타임라인**은 이벤트를 노래 시간 축 위에 놓으며, 재생 헤드, 스크럽,
줌, 트랜스포트 컨트롤, 모드 클러스터를 제공합니다.

- **트랜스포트 / 모드 클러스터** — 재생/스크럽과 모드 드롭다운(**Normal / Cam / Deco / Filter**)을 제공합니다.
- **카메라 키프레임 타임라인 (CAM)** — `MoveCamera`를 위한 제대로 된 작업 공간입니다.
  - 속성 레인은 **위치 / 회전 / 줌**이며, 시작+지속 박자로 트윈 바를 그립니다.
  - **가감속 선택기** — 곡선을 실시간으로 그린 가감속 그리드입니다 (키프레임 우클릭).
  - **커스텀 베지어** — 드래그 가능한 제어점 2개로, 적용 시 Linear 세그먼트로 분해됩니다.
  - **그래프 편집기** — AE 스타일 값-시간 그래프입니다 (탭 X/Y/회전/줌). 다이아몬드를 선택하거나
    값 드래그·타이밍 조절·우클릭 가감속 지정을 할 수 있으며, 음악 박자 X축과 자체 줌/팬을 갖습니다.
  - 키프레임을 **드래그해 타이밍을 조절**하고, 인라인 인스펙터 행, X·Y 링크 토글, 타이밍 조절 시 분할을 지원합니다.
- **Deco / Filter 모드** — 장식 태그별 / 활성 필터별 레인으로 빠르게 탐색합니다.

## 빠른 차팅 모드 (`Q`)

빠른 채보 작성을 위한 모드입니다. 켜져 있는 동안 타임라인이 숨겨지고 다음 키가 활성화됩니다
(에디터 한정, 입력 중일 때는 제외). 아래 키는 **모두 다시 지정할 수 있습니다** — 설정 ▸ 단축키에서 바꿉니다.

| 키 | 동작 |
|---|---|
| `I` | 선택한 타일의 **소용돌이**를 토글합니다. |
| `O` | **속도 설정** — 프롬프트(BPM 또는 배수)로 SetSpeed 이벤트를 만듭니다. |
| `[` / `]` | 선택한 타일의 SetSpeed 값을 **절반 / 두 배**로 만듭니다. |
| `Shift+P` | **일시정지** — 박자 프롬프트로 Pause 이벤트를 만듭니다. |
| `Shift+L` | **타일 위치** — X/Y 프롬프트로 PositionTrack 이벤트를 만듭니다. |
| `Shift+R` | **타일 이동** — 박자와 X/Y 프롬프트로 선택한 타일에 MoveTrack 이벤트를 만듭니다. |
| `Shift+O` | **홀드** — 지속 시간 프롬프트로 Hold 이벤트를 만듭니다. |
| `U` | 선택한 타일의 이벤트를 **편집**합니다. 이벤트가 하나면 바로 속성이 열리고, 여러 개면 각 속성을 미리 보여 주는 번호 목록이 열립니다(`1`–`9`나 클릭으로 선택). `Enter`로 적용하고 닫으며, `Esc`로 닫고, `Tab`으로 입력란을 이동합니다. |
| `Shift+G` | **각도 패드** — 타일 묶음을 한 번에 추가하는 플로팅 필드입니다. |
| `Shift+K` | 빠른 차팅 모드 자체를 토글합니다 (모드가 꺼져 있을 때도 동작합니다). |
| `Shift+F` | **Hz 도구** — 주파수로 차팅합니다 (아래 참조). 모드가 꺼져 있어도 동작합니다. |

### 각도 패드 문법

공백으로 구분된 **상대적** 각도입니다.

- **수식** — 토큰마다 계산합니다: `180-30`, `360/8`, `2*45`.
- **소용돌이** — 끝에 `t`를 붙이면 해당 타ㅔ에 소용돌이가 추가됩니다: `30t 30t 180`.
- **그룹 반복** — 괄호로 묶고 곱합니다: `(30t 150 180 180 180)*4`. 그룹은 중첩할 수 있습니다.

각도 패드는 **복제할 수 있으며**(각자 값을 스크래치 프리셋으로 보관합니다) 드래그할 수 있습니다.
모드를 켜면 툴바의 하위 메뉴와 아래쪽 키 힌트를 모두 피하는 **우측 상단**에 패드가 열립니다.
마지막 패드까지 모두 닫을 수 있으며, `Shift+G`로 새 패드를 엽니다.

**소용돌이 버튼 — 첫 타일의 소용돌이를 첫 회차에만 반전합니다.**
맨 앞 소용돌이가 *이번 한 번만* 불필요할 때 유용합니다. 진입
방향의 성질이지 패턴의 성질이 아니므로 첫 회차에만 적용됩니다. 켜져 있으면 강조됩니다.

**미리보기** — 패드가 설치할 타일이 반투명하게 그려지며, 입력하는 대로 갱신됩니다.
**Hz 도구**도 자기 묶음을 같은 방식으로 미리 보여 줍니다. Hz 도구 창이 열려 있으면 그쪽이 미리보기를
가져갑니다. 두 패널이 매 프레임 서로 뺏으면 깜빡이기만 하기 때문입니다.
배치와 똑같은 회전 규칙으로 계산하므로 결과와 어긋날 수 없습니다. 주변의 실제 타일을 건드리지 않고
미리보기 타일끼리만 연결합니다(MSM의 미리보기는 이웃 타일을 수정하는데, 그러면 패드가 열려 있는 동안
실제 트랙이 잘못 그려집니다). 그래서 기준 타일과의 이음매가 아주 조금 어긋납니다. 최대 200타일입니다.

**`× n` 반복 횟수** — 표현식을 *n*번 놓습니다. 마우스를 올리면 **▲▼ 조절 화살표**가 나타납니다. `(…)*n` 그룹 문법과 일부러 분리했습니다. 반복을
텍스트에 넣으면 `t` 버튼이 *모든* 사본의 첫 타일을 뒤집지만, 횟수로 두면 표현식이 하나의 **단위**로
남아 맨 앞 소용돌이를 빼는 효과가 첫 회차에만 적용됩니다. 경로가 이미 원하는 방향으로 들어올 때
바로 이것이 필요합니다. 회전 방향은 반복 사이에 이어지므로 나머지 회차도 정확히 계속됩니다.

헤더에는 **지우기** 버튼(휴지통 아이콘 — 같은 줄의 `×`는 이미 닫기입니다)과 패드 도움말을 여는
**`?`**도 있습니다.

**도형 라이브러리에 추가** — 배치 버튼 옆의 회색 버튼이 패드의 표현식을(반복 포함) 도형 라이브러리의
**각 패드에서 추가** 카테고리에 반복 1로 저장합니다. 패드 표현식은 이미 묶음 전체를 적어 둔 것이기 때문입니다
(`(…)*n` 그룹은 저장 전에 펼쳐집니다).

## Hz 도구 (툴바 ♪ 칸 · `Shift+F`)

각도 대신 **주파수**로 차팅합니다. 차터 A°인 타일은 `A/180` 박자를 차지하므로, BPM이 B일 때:

```
H = 180·B / A     분당 타수              A = 180·B / H = 3·B / F
F = H / 60        초당 타수 (Hz)         H = F · 60
```

175 BPM에서 20 Hz 드르륵은 `3 × 175 / 20` = **26.25°**입니다.

**BPM이 두 종류**이며, 이 구분이 도구의 핵심입니다.

- **도형 BPM**은 묶음이 재생되어야 할 템포이며 **결과값**입니다. 원하는 음과 도형에 필요한 각도를
  고르면 `도형 BPM = 각도 × Hz ÷ 3`이 따라 나옵니다. 미리 알 수 없는 값을 도구가 알려 주는 것입니다.
  16각형 원에서 20 Hz 드르륵은 1050 BPM이 필요합니다.
- **기준 BPM**은 현재 채보의 BPM(레벨 BPM × 기준 타일의 속도 배수)이며 선택에서 읽어 옵니다.
  **자물쇠로 고정**하면 선택을 따라가지 않습니다(값을 직접 입력해도 고정됩니다. 다음 클릭에 조용히
  지워지는 기준 BPM은 함정이기 때문입니다).
  음높이 계산에는 쓰이지 않고 두 가지 역할만 합니다. 아래 표시되는 **속도 변경** 비율의 분모이고,
  묶음 길이를 세는 기준입니다(`박자 = 타일 수 × 기준 BPM ÷ (60 × Hz)`).
- **Hz / 각도 / 도형 BPM은 하나의 식으로 묶여** 있어 셋 중 둘만 자유롭습니다. 각 줄의 **자물쇠**로
  고정할 값을 정하며, 아무것도 잠그지 않으면 도형 BPM이 모든 변화를 흡수합니다. 도형 BPM을 잠그면
  ("낼 수 있는 속도가 이만큼이다") 대신 각도가 움직입니다. 분당 타수는 Hz × 60입니다.
- **정확한 음높이 (정지로 채우기)**를 켜면 길이와 음높이가 동시에 정확해집니다. 둘이 충돌하는
  이유는 타일 수가 정수이기 때문이므로, 남는 시간을 **정지(Pause)** 이벤트가 흡수합니다. 묶음은
  일부러 짧게 내림하여 목표 주파수를 센트 단위까지 정확히 낸 뒤, 지정한 길이의 나머지만큼 멈춥니다.
  원 모드에서는 셋 다 정확해집니다. 175 BPM에서 4박자, 16각형 20 Hz는 닫힌 1바퀴 16타일이 2.333박자
  동안 재생되고 정지가 1.667박자입니다. 정지는 묶음의 마지막 타일에 들어가며, 되돌리는 SetSpeed도
  같은 타일에 함께 넣어 정지가 빠른 템포가 아닌 구간 박자로 세어지게 합니다.
- **길이 (박자)**는 정확히 맞으며, 음높이보다 우선합니다. N개 타일을 F Hz로 치면 도형과 무관하게
  N/F초가 걸리므로, 지정한 박자를 정확히 채우려면 `실제 Hz = 타일 수 × 기준 BPM ÷ (60 × 박자)`가
  됩니다. 타일 수는 정수이므로 주어진 길이에서는 *사다리꼴로 띄엄띄엄한* 주파수만 낼 수 있습니다.
  **실제 Hz**에 실제로 나올 값과 **센트** 오차가 함께 표시됩니다(±5를 넘으면 강조, 반음은 100).
  음높이를 맞추려고 길이를 건드리지는 않습니다.
- **완전한 원** — 묶음을 닫힌 고리로 만듭니다. 차터 A인 타일은 진행 방향을 `180 − A`만큼 돌리므로,
  `N × (180 − A) = 360`일 때 정확히 닫힙니다. 즉 정N각형이 되고 각도는 `180 − 360/N`으로 고정됩니다.
  **변 수**를 입력하면 그 원에 필요한 BPM(자물쇠에 따라 Hz)이 표시됩니다. 변이 많은 매끄러운 원은
  타일마다 조금씩만 돌아야 하므로 드르륵 주파수에서는 아주 빠른 구간이 필요한데, 그것을 아래의
  SetSpeed가 대신 써 줍니다. **바퀴 수**는 같은 다각형을 다시 그립니다. 16각형 10바퀴는 원 10개에
  걸친 160타일이며, 160각형 원 하나가 아닙니다(그쪽은 각도가 훨씬 넓어집니다).
- **원 간격 벌리기**(바퀴가 2 이상일 때) — 바퀴는 *같은* 다각형을 다시 그리므로, 이 옵션이 없으면
  모든 원이 정확히 겹쳐 하나의 고리로 보입니다. 첫 바퀴 이후 각 바퀴의 첫 타일에 **길 위치**
  (PositionTrack) 이벤트를 넣고, **간격 X / Y**를 직접 지정합니다. 오프셋은 상대값이라 누적되므로
  바퀴마다 같은 값을 주면 원이 나란히 놓입니다(4바퀴에 X = 6이면 0, 6, 12, 18). 미리보기도 같은
  이동을 적용하므로 보이는 자리가 실제 자리입니다.
- **완전히 닫힌 원**(기본 켜짐)이 그 닫힘을 강제합니다. 켜져 있으면 타일 수가 정수 바퀴여야 하므로
  선택지가 성기고 음높이가 그 대가를 치릅니다. 오차는 센트로 표시되어 비용이 보입니다. 끄면 곡률은
  그대로 두되 도중에 멈출 수 있어, 타일 수가 이상값에 가장 가까운 정수가 되고 음높이는 정수 타일이
  허용하는 한 가장 정확해지며 도형은 호로 끝납니다. 175 BPM에서 4박자일 때 16각형 1바퀴는 16타일로
  거의 한 옥타브가 낮지만, 같은 곡률을 27타일(1.69바퀴)에서 멈추면 −27센트입니다. **길이는 어느
  쪽이든 정확합니다.** 이 옵션은 나머지 둘 중 무엇을 양보할지만 고릅니다.
- **변 수·바퀴 수 추천**(닫힌 원에서만 — 제약을 끄면 타일 수가 이미 음높이 최적입니다)은 지정한 길이에서 가장 정확한 조합을 찾아 줍니다. 음높이 오차는 변 수 × 바퀴 수의 *곱*에만
  좌우되므로, 이상적인 타일 수에 가장 가까운 곱(닫힌 고리가 그 길이에서 낼 수 있는 최선)을 고른 뒤
  요청한 변 수에 가장 가까운 약수로 나눕니다. 길이가 길수록 정확해집니다. 175 BPM에서 20 Hz 원은
  1박자면 7×1에 +36센트, 4박자면 9×3에 −27센트이며, 길이는 두 경우 모두 정확합니다.
- **이 BPM에 맞춰 SetSpeed 작성** — 각도는 기준 BPM을 전제로 계산되므로, 기준 타일이 그 BPM으로
  재생되고 있지 않으면 도형이 아무리 정확해도 주파수가 어긋납니다. 기본으로 켜져 있으며, 첫 타일에
  타일의 속도는 그 타일에서 *빠져나가는* 이동을 지배하므로, 배수(도형 ÷ 기준)는 선택했던
  **기준 타일**에 들어가고 역수는 묶음의 **마지막 타일**에 들어갑니다. 그러면 묶음 전체가 빠른
  쪽에 남고 빠져나가는 이동만 원래 속도가 됩니다. 트랙 끝이라면 뒤가 없으므로 되돌리지 않습니다. 두 BPM이 이미 같으면 이벤트를 만들지 않습니다. 배치 후 상태줄에
  어느 쪽인지 표시됩니다.
- **음 건반** — 피아노 건반입니다 (`−`/`+`로 옥타브 이동). 창 너비가 허용하는 만큼 옥타브가 늘어나며, 창을 넓히면 고정 건반 옆에 빈 공간이 생기는 대신 옥타브가 통째로 추가됩니다. 누르기 어려울 만큼 좁은 건반은 만들지 않습니다. 건반을 누르면 목표 주파수가
  그 음의 음높이로 설정되어, 멜로디를 드르륵으로 옮길 때 쓸 수 있습니다. MIDI 입력 장치가
  아니라 음을 고르는 UI입니다.
- **음률 하위 메뉴** (`음률 +`) — **EDO**(옥타브당 등분, 1–72)와 격자를 고정하는 기준 음높이를
  설정합니다: `f = 기준 × 2^((옥타브 − 기준옥타브) + (단계 − 기준단계)/EDO)`. 기본값은 12-EDO,
  4옥타브 9단계, 440 Hz — 즉 표준 음률이므로 건드리지 않으면 평범한 피아노 건반입니다. 다른
  EDO에서는 피아노 대신 등분 단계 띠가 표시되고(옥타브 시작 단계를 밝게 표시), 음 이름은
  `단계\EDO` 표기를 씁니다. 12가 아닌 곳에서 계이름은 사실과 다르기 때문입니다. 등분이 많으면
  2옥타브 대신 1옥타브만 보여 줍니다.
- **배치**는 선택한 타일 뒤에 묶음을 추가하며(되돌리기 1회), 경로의 진행 방향과 이미 걸려 있는
  소용돌이를 그대로 따릅니다. **각도 패드로 보내기**는 `(26.25)*16` 형태로 넘겨 소용돌이나 꼬리를
  덧붙인 뒤 확정할 수 있게 합니다.

## 도형 라이브러리

재사용 가능한 **도형**의 도킹형·크기 조절형 팔레트입니다. 각 도형은 기준 각도를
키 개수별 변형으로 나눈 것으로, 반복 동타로 삽입됩니다.

- **카테고리** — 접이식 레일입니다. **기본 제공**(90° / 120° / 240° / 270°)과 사용자 정의
  카테고리가 있습니다. `+ 카테고리` / `+ 도형`으로 추가하고, 인라인으로 이름을 바꾸며, `×`로 삭제합니다 (확인 팝업 포함).
- **변형** — 각 도형은 키 개수 변형을 제공합니다 (예: 2키, 3키). 변형마다:
  - **편집 가능한 각도** — 각 타일의 차터가 필드입니다. 하나를 편집하면 나머지가 재조정되어
    합이 기준 각도를 유지합니다. `t`는 소용돌이 타일을 표시합니다.
  - **반복 (n)** — 몇 개의 유닛을 추가할지 정합니다. 기본 제공 도형은 별을 닫는 값을 그대로
    쓰고, **직접 만든 도형은 1**이 기본이라 적은 그대로 배치됩니다.
  - **미리보기** — 실시간 경로 렌더링입니다. 둥근 ADOFAI 스타일 타일, 빨강/파랑 소용돌이 마커
    (타일의 결과 각도가 180° 이상이면 파랑), 시작점의 플래닛을 보여줍니다.
  - **삽입** — 선택한 타일에 묶음을 추가합니다 (되돌리기 1회). 타일이 선택되지 않았으면
    기준이 될 타일이 없으므로 아무것도 하지 않고 안내를 표시합니다.
  - **회전** — 도형을 x축을 따라 반전합니다 (유효한 두 소용돌이 패리티 중 다른 쪽).
  - **소용돌이는 겹쳐 쌓지 않습니다.** 게임은 이벤트마다 회전 플래그를 토글하므로 한 타일에 소용돌이
  이벤트가 둘이면 서로 상쇄되면서 표시만 남습니다. 게다가 묶음의 첫 소용돌이는 기준 타일에 놓이는데,
  거기야말로 사용자가 이미 소용돌이를 넣어 두었을 가능성이 가장 큰 자리입니다. 이제 모든 배치는
  덧붙이는 대신 *토글*합니다. 기존 이벤트를 제거하므로 회전 결과는 같고 데이터는 유효하게 남습니다.
- **소용돌이 타일 위에서는 자동으로 반전됩니다** — 회전 방향이 반시계인 타일(그 타일이나
    앞선 타일에 소용돌이가 있는 경우)에 삽입하면 도형이 **상하로 반전되어** 들어가며,
    각도와 소용돌이는 새 트랙에 넣을 때와 똑같이 유지됩니다. 원래 방향을 유지하면 모든
    각도가 `360 − 각도`로 읽혀서 30° 겹눈이 330° 박자가 되기 때문입니다.
- **커스텀 도형** — `+ 도형`으로 양식을 엽니다. 이름, 카테고리, 그리고 **각도 표현식**
  (같은 `30t 30t 180` 표기)을 입력하거나, **선택에서 가져오기**로 선택한 에디터 타일의 각도와
  소용돌이를 캡처합니다. 커스텀 도형과 카테고리는 재시작 후에도 **유지됩니다**.
- **크기 조절** — 모서리나 변을 드래그합니다. 레일과 미리보기 열이 새 크기와 도킹에 맞게 재배치됩니다.

## 레벨 설정 & 장식

레벨 설정 패널은 게임 자체의 속성 레지스트리를 사용해 Sapphire가 직접 그립니다. 이 패널은
왼쪽 사이드바에서 이벤트 팔레트와 나란히 탭으로 열립니다. 사이드바 위쪽의 탭 줄로 서로
전환하며, 열려 있는 탭을 다시 누르면 사이드바가 탭 이름만 남은 세로 막대로 접힙니다. 창을 **탭
막대 위에** 끌어다 놓으면 탭으로 추가되고(도형 라이브러리, 마법진, 트랙 도구, 장식 도구, Hz
도구), 막대 위에 올리면 강조 표시로 알려 줍니다. 탭 자체를 막대 밖으로 끌어내면 다시 독립 창이
되며, 끌던 중 막대 위에서 놓으면 그대로 탭에 남습니다. 사이드바 **본문**에 놓으면 기존처럼
사이드바가 분할되지만, **비어 있는** 사이드바에는 나눌 본문이 없으므로 그대로 탭이 됩니다.
오른쪽 사이드바도 똑같이 동작하며, 처음에 탭이 하나도 없을 뿐입니다.

- **노래 파형** — 타임라인 아래쪽에 **오디오** 트랙이 따로 생기며, 이벤트 레인과 같은 시간축에
  맞춰 그려집니다. 노래마다 한 번만 만들고 UV로만 이동하므로 확대·이동에 비용이 들지 않으며,
  레벨 오프셋만큼 함께 밀려서 실제로 들리는 소리와 맞습니다. 스트립 오른쪽 열의 **♪ AUDIO**
  버튼으로 트랙을 켜고 끄며(기능 탭에도 같은 스위치가 있습니다), 노래를 읽는 중에는 버튼이 흐리게
  표시되고 아예 읽지 못하면 트랙이 높이를 차지하지 않습니다.
- **오디오 창** — 레벨 설정의 오프셋 칸 옆 `오디오` 버튼으로 엽니다. **분석**을 누르기 전에는
  아무것도 분석하지 않습니다. 레벨을 열 때마다 디코딩과 템포 분석을 돌리면 에디터가 느리게 열리는
  것으로 체감되고, 대부분의 작업에서는 필요하지도 않기 때문입니다. 그전까지 창에는 그 버튼만
  있으며, 분석이 끝나면 버튼이 `다시 분석`으로 바뀌고 나머지 UI가 나타납니다. **고급**에서는 창
  길이·간격·매끄러움 λ·템포 분할 수를 직접 조정할 수 있어, 기본값으로 잘 안 되는 곡에 대응할 수
  있습니다. 파형 위에서
  스크럽을 끌어 위치를 밀리초로 확인하고, ▶로 그 지점부터 들어 볼 수 있습니다. 파형 아래에는 곡 전체의 **템포 곡선**이 같은 시간축·같은 확대 배율로 그려져, 가속·감속과 기본
  BPM 변화가 일어나는 지점을 그대로 볼 수 있고 스크럽 위치의 템포가 함께 표시됩니다. 모든 구간에서 모든 템포를 채점한 뒤, 구간별로 따로 고르지 않고 전체 점수에서 템포가 움직인
  거리에 *비례하는* 비용을 뺀 값이 최대가 되는 **경로**로 해독합니다. 비례(선형)라는 점이
  중요합니다. 제곱 비용은 한 번에 d만큼 뛰면 L·d²를 물리지만 같은 거리를 N번에 나누면 L·d²/N만
  물리므로, 모든 변화를 완만한 경사로 뭉개도록 부추깁니다. 실제로 250→270인 곡이 256·260·264를
  거치는 방황으로 보였습니다. 선형 비용은 어떻게 나누든 총액이 같으므로, 계단인지 경사인지는
  오디오가 결정합니다. 구간별로
  고르면 직전 값에 가중치를 줘도 표류합니다. 한 걸음 한 걸음이 제자리보다 아주 조금 나을 뿐이고
  되돌리는 힘이 없어서, 3분 내내 같은 템포인 곡이 14%나 벗어났습니다. 그다음 전역 기준값으로
  옥타브를 맞추고(자기상관은 박과 반박을 구분하지 못하기 때문입니다), 곡선 전체를 공통 2의
  거듭제곱으로 옮겨 채보자가 실제로 쓰는 **80–350 BPM** 구간에 넣습니다. Parallel Universe
  Shifter는 채보가 300인데 68–133으로 읽히는데, 두 옥타브 아래의 같은 템포입니다. 점마다 따로
  접지 않고 공통 배수를 쓰는 이유는, 따로 접으면 경계를 넘는 지점마다 선이 끊기고 이 그래프의
  본질인 상대 변화가 망가지기 때문입니다. 그래프에 마우스를 올리면 그 지점의 템포가 숫자로
  표시되고, 왼쪽 가장자리에 범위가 함께 적힙니다. 템포가 일정할 때는 그래프의 배율을 전역
  추정값에 맞춥니다. 표시되는 값은 곡 전체를 미세하게 훑은 뒤 정수로 맞춘 값인 반면 그래프의
  점들은 격자 중심값이라, 그렇게 하지 않으면 250인 곡이 251.5에 놓인 선 위에 250이라고 적히게
  됩니다. 여기서도 공통 배수 하나만 쓰므로 상대 변화는 그대로입니다. 250에서 270으로 바뀌는 PP BREAKER는 250.0과 269.2의 평탄 구간으로 분리되고, 템포가 일정한
  初音ミクの激唱은 처음부터 끝까지 0.9% 이내로 평평하게 나오며, 240으로 채보된 Second Revolution도 3분 내내 240.0 ±0.5%로 평평하며, 단일 추정이 통하지 않던 Megantus는 215까지 내려갔다 268까지 올라간 뒤
  242로 정착하는 실제 곡선으로 드러납니다. 가장 까다로운 두 채보에서도 잘 동작합니다.
  *Parallel Universe Shifter*는 95에서 131까지 올라갔다 85를 거쳐 70까지 내려오는 연속적인 흐름을
  그대로 보여 주고, *TremENDouS*는 채보 기본 BPM의 2배에서 시작해 33% 상승하며 이는 채보 자체의
  속도 이벤트에 적힌 가속과 일치합니다. 선은 **신뢰도에 따라 밝기가 달라집니다**. 템포가 움직이는
  구간에서는 분석 창 안에서 한 박으로 뭉칠 수 없어 신뢰도가 낮아지므로, 어두운 부분은 "틀렸다"가
  아니라 "이 구간은 템포가 움직이거나 박이 불분명하다"는 뜻입니다. 세로 축은 검출된 템포를
  기준으로 최소 ±12% 범위로 고정되고 기준선이 함께 표시되므로, 일정한 곡은 일정한 선으로 보입니다.
  실제 변동 폭은 상단 표시줄에 백분율로 나옵니다.

  창은 단일 **템포** 값도 함께 보고합니다. 온셋 플럭스의 자기상관으로 주기를 잡고, 온셋이 한 박에
  얼마나 뭉치는지를 최대화하는 미세 탐색으로 다듬기 때문에 채보에 쓸 만한 정밀도가 나옵니다. 스스로
  값을 쓰지는 않으며, 표시가 *확실* 또는 *일정*일 때만 버튼이 동작합니다. 집중도만으로 판정하면
  기준이 지나치게 엄격했습니다. 집중도는 온셋 히스토그램이 얼마나 뾰족한지를 재는 값이라 템포가
  맞는지가 아니라 곡의 질감에 좌우되고, 그래서 끝까지 250 BPM인 곡을 249.90으로 정확히 읽고도
  불확실이라고 표시했습니다. 이제는 **교차 확인**도 인정합니다. 전역 추정과 템포 곡선은 같은
  포락선을 서로 다른 방식으로 지나가므로, 곡선이 평평하게 유지되면서 전역 추정과 같은 값에
  도달하면 서로 다른 두 방법이 일치한 것으로 봅니다.
  한 라이브러리의 곡 49개와 별도로 떼어 둔 157개로 측정한 결과, 이 기준을 넘는 경우는 약 1/4이고
  그중 약 3/4이 채보자의 BPM과 0.1% 이내, 10곡 중 9곡이 0.5% 이내로 일치합니다(기준 없이는 1/3
  수준). 곡선이 템포가 일정하다고 확인해 주면, 추정값을 앞 30초가 아니라 **곡 전체의 모든 온셋**에 대해
  다시 훑습니다. 0.05% 어긋난 템포는 30초 동안 16분의 1박밖에 밀리지 않아 여전히 잘 뭉치지만,
  4분이면 반 박이 밀려 확실히 갈라집니다. 그다음 0.04% 이내면 정수(또는 .5)로 맞춥니다. 채보자가
  쓰는 BPM은 대부분 정수이기 때문입니다(서로 다른 BPM 89개 중 83%가 정수, 10%가 .5로 끝납니다).
  그래서 249.96은 250이 됩니다. 정말 특이한 값들은 건드리지 않으며, 그것들은 실수가 아니라 의도된
  값입니다. Pause 이벤트가 없던 시절에 쉼을 메우거나 불규칙한 인트로를 흡수하려고 BPM을 미세하게
  틀어 둔 옛 레벨에 몰려 있고, 그중 정수에 가장 가까운 값도 0.070% 떨어져 있습니다. 자기상관은 박과 반박을 구분하지 못하므로 배수는 추측하지 않고 `÷4 ÷2 적용 ×2 ×4`
  사다리와 `×1.5 ÷1.5`로 제공합니다. 실제로 채보자가 쓰는 값이 2의 거듭제곱이기 때문입니다(배포된 채보 429개의 속도 배수
  31,220건 중 78.5%가 정확히 2의 거듭제곱이며, 떼어 둔 집합에서 확실 판정을 받은 곡은 모두 그렇습니다).
  나머지 대부분은 마법진 보정(×3, ×1.5, ×4⁄3, ×6⁄5)으로, 각도를 바꾸면서도 입력 템포를 유지하므로
  이것도 템포 변화가 아닙니다. 둘 다 아닌 비율이야말로 기본 BPM이 실제로 바뀌었다는 신호입니다. 자기상관은 박과 반박을 구분하지 못하므로 배수는
  추측하지 않고 버튼으로 제공합니다. `메트로놈`을 켜면 레벨 자신의 격자(검출값이 아니라 레벨의 BPM과 오프셋)로 클릭음이 납니다. 곡
  위에 얹어 들어 보면 두 값이 맞는지 바로 확인할 수 있고, 클릭이 음악에 얹히면 맞는 것입니다.
  마디 첫 박은 강조됩니다. 격자는 한 간격을 반복하는 대신 **검출된 템포를 따라갑니다**. 각 박의
  길이를 그 박이 놓이는 지점의 템포 곡선에서 읽고, 오프셋에서 곱해 나가는 대신 적분해 나가므로
  가속하는 곡에서도 몇 마디 만에 클릭이 뒤처지지 않습니다. 곡선은 먼저 레벨 자신의 옥타브로
  접히기 때문에, 검출값이 절반이나 두 배에 있더라도 클릭 밀도는 검증하려는 격자와 비교 가능한
  상태로 유지됩니다. 클릭은 프레임 루프가 아니라 오디오 시계에 *예약*됩니다. 프레임 경계는
  실제 박에서 최대 16ms까지 벗어나는데, 이는 확인하려는 오프셋 오차와 같은 크기이기 때문입니다.
  휠로 커서를
  기준으로 확대하고(창 폭 최소 50ms), Shift+휠이나 오른쪽·가운데 버튼 드래그로 이동하며, 버튼
  줄의 `− / + / 전체`로도 같은 조작을 할 수 있습니다. 재생이 창 밖으로 나가면 화면이 따라가고,
  스크럽을 가장자리 밖으로 끌면 멈추지 않고 화면이 함께 이동하므로 확대한 상태에서도 곡 전체를
  훑을 수 있습니다. `노래`와 `메트로놈` 슬라이더로 두 음량을 따로 맞출 수 있습니다. 클릭이 어택에
  얹혔는지 판단하는 일은 타이밍 문제이기 전에 균형 문제이기 때문입니다. 재생은
  컨덕터가 아니라 Sapphire 자체 오디오 소스로 하므로 에디터 시계가 어긋나지 않습니다.
  파형 위에는 레벨의 BPM과 오프셋으로 그린 **박자 격자**가 함께 표시되며(마디 선이 더
  밝습니다), 선이 파형의 어택에 얹혀 있으면 오프셋이 맞다는 뜻이라 눈으로 바로 판단할 수
  있습니다. `오프셋 추천`도 이 창에 있습니다. 오프셋이 아직 없는 레벨에서는 노래의 첫 소리(파형에
  표시)를 찾아 그대로 쓰고, 이미 오프셋이 있으면 두 가지 추정을 함께 써서 **보정**합니다. 가장 가까운
  어택과, **오디오에서 측정한 박자 격자**(앞 30초의 모든 온셋이 격자 위치를 함께 결정)입니다. 두
  값이 25ms 이내로 일치하면 어택이 맞은 것으로 보고 그 정밀도를 쓰고, 어긋나면 격자 쪽을
  택합니다. 레벨 115개와 별도로 떼어 둔 317개에서 이 조합이 두 추정 각각보다 모두 낫고, 30ms
  이내가 각각 88%와 76%입니다. 그래서 긴 노래의 3분 지점부터 시작하는 채보가 노래 맨 앞으로 끌려가지 않습니다. 절대
  음량이 아니라 국소 중앙값 대비 로그 에너지 상승으로 찾기 때문에, 처음부터 크게 시작하는 곡과
  잔잔한 앰비언스로 시작하는 곡을 같은 규칙으로 다룰 수 있습니다. 배포된 레벨 115개의 실제
  오프셋과 비교한 결과 오차 중앙값 9ms, 68%가 30ms 이내이며 항상 답을 냅니다.
- **다중 선택 우클릭** — 타일을 2개 이상 선택한 상태에서 그 안쪽을 우클릭하면 Sapphire 자체
  메뉴가 열리고(복사, 잘라내기, 삭제(안전), 소용돌이 추가, 반복, 복제, 이동) 선택은 그대로
  유지됩니다. 선택 밖을 우클릭하면 기존처럼 그 타일이 선택되고 단일 타일 메뉴가 열립니다. 다중
  선택 항목들은 아직 연결되지 않았으며, 누르면 그렇다고 알려 줍니다.
- **타임라인 높이** — 스트립 위쪽 가장자리를 끌면 이벤트 레인 높이가 조절되고(상한이 고정값
  대신 400까지 늘어났습니다), **오디오 트랙**의 위쪽 가장자리를 끌면 그 트랙만 따로 조절됩니다.
  둘은 성격이 다른 내용이라 하나의 조절기로 묶으면 어느 쪽도 원하는 값으로 맞출 수 없습니다.
- **패널 애니메이션** — 창과 드롭다운, 두 가지 컨텍스트 메뉴, 타임라인 스트립이 툭 나타나는 대신 기본 0.11초(`Ctrl+E` → 기타의 애니메이션 길이, 0–0.6초) 동안 페이드하며
  살짝 커집니다. 들어올 때는 감속, 나갈 때는 가속으로 처리합니다. `Ctrl+E` → 기타에서 끄면
  예전처럼 즉시 표시·숨김으로 돌아갑니다. 움직임은 알파와 `localScale`에만 주며 rect는 건드리지
  않습니다. 독 레이아웃이 매 프레임 크기와 위치를 쓰기 때문입니다. 사라지는 중인 패널은 독
  레이아웃에서 제외되므로, 사이드바 탭을 전환할 때 사라지는 패널과 나타나는 패널이 사이드바를
  나눠 갖는 일이 없습니다. 닫히는 드롭다운도 사라지기 시작하는 즉시 클릭을 받지 않아 다음 클릭을
  삼키지 않습니다.
  이벤트 패널에서 행을 펼치면 아래 행들이 밀려 내려가며 설정이 드러나고, 접으면 다시 올라오며,
  타일을 바꾸면 목록이 페이드되며 나타납니다.
- **호버 도움말** — 아이콘만 있는 버튼 위에 잠시 마우스를 올리면 이름이 표시됩니다. 각도 패드의 버튼과
  반복 스테퍼, 이벤트 패널의 펼치기/삭제 버튼, 이벤트 독의 아이콘, 팔레트의 카테고리 레일, 모든 창의
  닫기 버튼에 적용됩니다.
- **채보 분석** — 오디오 창의 `채보` 버튼을 누르면 레벨의 모든 속도 변화를 노래의 흐름과 대조해
  분류해 보여 줍니다. **분할**(2의 거듭제곱 비율)과 **마법진**(`180/각도` 비율 — 각도를 바꾸면서
  입력 템포를 유지하는 보정)은 템포 변화가 아니며, 그 밖의 비율이 기본 BPM이 실제로 바뀐
  경우입니다. 각 줄을 오디오 템포 곡선과 대조하므로, 정말 봐야 할 것은 서로 어긋나는 줄입니다.
  노래는 일정한데 기본 BPM이 바뀌었거나, 노래는 움직이는데 채보는 그대로인 경우입니다.
  `표시: 확인 필요`로 그것만 걸러 볼 수 있습니다. 게임이 이미 모든 SetSpeed를 접어 넣어 둔
  `scrFloor.speed`와 `scrFloor.entryTime`을 읽으므로 게임의 해석과 어긋날 수 없습니다.
- **노래에서 자동 설정** — 오디오 창의 `자동 설정`은 BPM과 오프셋을 오디오만으로 함께 씁니다.
  템포 추정은 채보를 전혀 보지 않으며, 그 값을 위상 계산에 되먹이면 격자까지 얻을 수 있어 아무
  설정도 없는 새 레벨을 곡만으로 시작할 수 있습니다.
- **색상 휠** — Sapphire의 모든 색상 값(레벨 설정, 이벤트 인스펙터, 장식, 파티클, Ctrl+E의 강조
  색상)에서 HSV 휠이 열립니다. SV 사각형, RGB·HSV 입력칸, 16진수 입력칸이 있고 알파를 쓰는
  값에는 알파 슬라이더가 붙습니다. 16진수 칸 옆의 색상 칩을 누르면 열리며, 드래그를 놓을 때
  값이 적용되므로 드래그 한 번이 실행 취소 한 단계가 됩니다.
- **Sapphire 입력칸에서의 Ctrl+Z** — 게임은 텍스트 입력칸에 포커스가 있으면 모든 에디터
  단축키를 무시하기 때문에, Sapphire 패널에서 값을 고친 뒤에는 실행 취소가 조용히 먹히지
  않았습니다. 이제 Ctrl+Z와 Ctrl+Shift+Z가 포커스를 풀고 에디터의 실행 취소 스택으로
  전달됩니다.
- **아티스트 허가 상태** — 레벨 탭 상단의 색상 칩이 아티스트의 승인 상태를 보여줍니다.
  클릭하면 전체 조건 문구가 펼쳐집니다. 아티스트가 설정되지 않았으면 칩이 표시되지
  않습니다.
- **장식 브라우저** — 태그별로 묶인 목록(접이식 폴더) 또는 썸네일 그리드로 봅니다.
  `+ 장식`으로 종류(**이미지 / 텍스트 / 오브젝트 / 파티클 / 컴포넌트**)를 고르고, `복제`로
  선택 항목을 복사하며, `삭제`로 제거합니다. 행을 선택하면 그 장식의 **인스펙터**가 별도의
  플로팅·크기 조절·도킹 가능한 창으로 열립니다 (`×`로 닫으면 선택도 함께 해제됩니다) —
  브라우저 목록 자체는 다시 배치되지 않습니다.
- **파티클·오브젝트 장식 편집** — 그라디언트 색상(모드: 단색 / 두 색상 / 그라디언트 / 두
  그라디언트 / 무작위, 그리고 색상 지점·투명도 지점 편집기), 실수 쌍과 속도 범위 필드,
  재생 / 정지 / 다시 시작 파티클 미리보기까지 완전히 편집할 수 있습니다. 오브젝트 장식은
  `objectType`에 따른 항목을 포함한 전체 속성을 제공합니다.
- **장식 이벤트 대상 태그** — 이벤트 트리가 각 장식 이벤트의 대상 태그를 보여줍니다. 펼친
  행에서는 번호 옆에, 접힌 그룹에서는 헤더에 그룹의 고유 태그 목록으로 표시합니다
  (`MoveDecorations` 이벤트 7개가 있는 타일이 더 이상 똑같은 행 7개로 보이지 않습니다).
- **이벤트 트리 선택** — 행을 클릭하면 선택됩니다(Ctrl은 토글, Shift는 범위 확장). 행 왼쪽의
  `▸` 버튼(이벤트 아이콘이 함께 표시됩니다)을 누르면 펼쳐집니다. 이벤트가 하나인 타일은 그 이벤트가 선택되고 펼쳐진 채로
  열리며, 여러 개인 타일은 첫 이벤트만 선택되고 트리는 접힌 채로 열립니다.
  입력란에 입력하는 중이 아니면 `↑` / `↓`로 선택을 한 행씩 옮기며, `Shift`를 누르면 범위가 늘어납니다.
- **이벤트 복사 / 붙여넣기** — 패널 선택 막대의 `복사`는 선택한 이벤트를 복사하고 알림으로 알려 줍니다.
  `Ctrl+V`(또는 타일 메뉴의 `붙여넣기`)는 선택한 모든 타일의 이벤트를 복사한 이벤트로 교체하고,
  `Ctrl+Shift+V`는 기존 이벤트 위에 추가합니다. 이후에 타일을 복사하면 두 키 모두 다시 게임 동작으로 돌아갑니다.
- **이벤트 트레이** — 눈에 보이는 클립보드입니다(이벤트 패널의 `트레이` 버튼, 또는 사이드바 탭으로 도킹).
  끌어다 놓을 때마다 그 드래그에 담긴 이벤트가 **폴더** 하나가 됩니다. 행, 그룹 머리글, 또는 여러 행을 선택한
  상태라면 선택 전체(종류가 섞여도 됩니다)를 끌 수 있습니다. 기존 폴더 위에 놓으면 그 폴더에 추가됩니다.
  폴더를 클릭하면 이벤트 목록이, 이벤트를 클릭하면 그 자리에서 속성을 편집할 수 있습니다(트레이의 복사본).
  폴더나 그 안의 이벤트 하나를 타일(또는 이벤트 패널 — 그 패널의 타일)로 끌어다 놓으면 추가되며, `Shift`를
  누른 채 놓으면 그 타일의 이벤트를 교체합니다. 이벤트 패널의 행을 다른 타일로 바로 끌어다 놓을 수도 있습니다.
  커서를 따라가는 카드가 놓일 위치를 알려 주며 `Esc`로 취소합니다. 트레이의 모든 항목은 복사본이며 세션
  동안 유지됩니다.
- **레벨 변수** — 레벨 설정 레일의 `변수`에서 레벨의 이름 붙은 값 목록을 엽니다(`bpm = 180`,
  `beat = 60/$bpm`; 변수는 자기보다 위에 있는 변수를 쓸 수 있습니다). 이벤트 속성, X/Y 성분, 레벨 설정 등
  **모든** 숫자 입력란에 `$beat*2` 같은 수식을 입력하면 입력란은 수식을 유지하고(강조색 표시, 마우스를 올리면
  현재 값 표시) 이벤트에는 계산 결과가 저장됩니다. 변수를 고치면 레벨의 모든 수식이 다시 계산되며 한 번에
  되돌릴 수 있고, 이름을 바꾸면 그 변수를 쓰는 수식도 함께 바뀝니다. 저장된 `.adofai`에는 숫자만 들어가므로
  모드 없이도 플레이할 수 있고, 수식은 게임이 무시하는 `sapphire` 항목에 함께 저장됩니다. 모드 없는 에디터에서
  다시 저장하면 숫자는 남고 수식은 사라집니다.
- **스크립트 (모드 없이 동작하는 실행 중 로직)** — 레벨 설정 레일의 `스크립트`에서 코드 편집기(줄 번호,
  색 구분, 입력 중 오류 표시)를 엽니다. `컴파일`하면 스크립트가 일반 이벤트로 바뀌므로 모드 없는 게임에서도
  플레이됩니다. 게임이 실행 중에 기억하는 것은 `SetInputEvent`의 키 → 이벤트 표뿐이고, 발동한
  `SetInputEvent`가 이 표를 바꿉니다. 컴파일러는 이를 이용해 상태 기계를 만들며, 호스트 타일에 상태와 키마다
  태그된 이벤트 묶음을 둡니다.

  ```
  flag lights                    # off / on
  counter hits 0..3 wrap         # wrap이 없으면 양 끝에서 멈춥니다
  on key Up nohit:               # Up Down Left Right Action1 Action2 Confirm Any · release · nohit
      toggle lights
      hits += 1
      if hits == 3:
          run flash              # "flash" 태그가 붙은 모든 이벤트를 복사합니다
  when lights:                   # 조건이 참이 될 때마다 실행합니다
      run grey
  on miss at 40:                 # 판정은 타일마다 발동하며 run만 할 수 있습니다
      run shake
  ```

  `state mode = calm, wild`는 이름 붙은 상태를 선언하고, 조건에는 `== != < > <= >=`, `and`, `or`,
  `not`을 쓸 수 있습니다. `run`에 쓰는 이벤트는 **템플릿**입니다. 태그를 붙여 두면 컴파일이 호스트 타일
  (`host N`, 기본값 0)에 활성 복사본을 두고 원본은 비활성화합니다. 경로·타이밍 이벤트(SetSpeed, Twirl,
  Pause 등)는 발동할 수 없으므로 건너뜁니다. `nohit`가 없으면 키 입력도 타격으로 처리됩니다. 모든 변수의
  조합은 최대 256가지입니다. `제거`는 컴파일된 이벤트를 지우고 템플릿을 다시 켭니다. 레벨 처음부터
  테스트하세요.

## 숫자 입력란

Sapphire의 모든 숫자 입력란은 바닐라 인스펙터처럼 **사칙연산**을 지원합니다. `180*2`,
`100/3`, `(1+2)*45`, `360/8` 처럼 입력하면 확정할 때 계산됩니다. `^`, `%`와 상수 `pi` /
`tau` / `e`도 쓸 수 있습니다. 바닐라와 달리 정수 나눗셈이 아니므로 `10/4`는 `2`가 아니라
`2.5`입니다. 텍스트 입력란(태그, 이미지 경로)은 계산되지 않습니다.

**Tab** / **Shift+Tab**을 누르면 입력란을 확정하고 같은 창의 다음 / 이전 입력란으로 이동합니다.
입력란에 입력하는 동안에는 숫자와 Enter가 팔레트나 툴바 단축키로 전달되지 않습니다.

## 업데이트

Sapphire는 세션마다 한 번 GitHub 릴리스를 확인하고, 새 빌드가 있으면 토스트를 띄웁니다.
클릭하면 내려받아 현재 설치본 위에 덮어쓰며, 게임을 재시작하면 새 버전이 적용됩니다.
내려받은 파일은 GitHub가 게시한 SHA-256 다이제스트로 검증하고, 모드 폴더를 벗어나는
압축 항목은 거부합니다.

- **설정 → 업데이트** — 설치된 버전, 실시간 상태, 자동 확인 및 프리릴리스 토글,
  `지금 확인`, 토스트 미리보기가 있습니다.
- **다른 모드와 공존** — 토스트는 Quartz와 같은 오른쪽 위 모서리에 표시됩니다. Sapphire는
  그 자리에 있는 다른 모드의 업데이트 토스트를 감지해 위에 겹치지 않고 아래에 쌓이므로
  둘 다 읽을 수 있습니다.

## 스킨 & 크롬

- 게임 에디터 UI의 **다크모드 리스킨**입니다 (되돌리기 가능, 가드 기반). Sapphire 블루 강조색을 사용합니다.
- **파일 칩 / 메뉴**, 패널 레일, 이벤트 독 — 게임 자체 버튼을 프록시하는 현대적 크롬입니다
  (게임 로직을 재구현하지 않습니다).
- **플로팅 창** — 레벨 설정 팝업과 대화상자는 차단막이 없고, 드래그할 수 있으며, 위치를
  기억합니다 (일부는 크기 조절도 됩니다).
- **패널 배치 기억** — 열림/닫힘 상태와 위치가 한 세션 동안 유지됩니다. 게임을 다시 켜면
  기본적으로 초기화되며, `Ctrl+E` → 기타 → **재시작 후에도 패널 배치 유지**로 이 초기화를
  끌 수 있습니다 (도형 라이브러리, 레벨 설정, Magic Shape, 트랙 도구, 장식 도구, Hz 도구).
- **화면 단축키 도움말** — 우측 하단 카드가 현재 상황에서 사용 가능한 키를 실시간으로
  보여줍니다. 이벤트 타임라인 위에 표시되며, 내용에 맞춰 높이가 조절되고, 헤더로 접을 수
  있으며, 끌 수도 있습니다 (`Ctrl+E` → 기능).

## 재생 & 기타 조정

- **연습용 피치** — `scnEditor.playbackSpeed`입니다 (게임의 네이티브 레버로, 히트사운드도 따라갑니다).
- **피치 오버레이**를 제공합니다.
- **WASD** 카메라 팬을 지원합니다.
- **자동플레이 일시정지 키**와 실시간 **타일 각도 표시**를 제공하며, 선택한 타일의 **체감 BPM**을 옆에
  함께 보여 줍니다(SetSpeed가 적용된 BPM × 180/각도, 즉 실제로 치는 속도입니다. 90° 타일은 두 배로
  표시됩니다). `Ctrl+E` → 기능 → **체감 BPM**에서 켜고 끕니다.
- **편집 / 플레이 모드** — 타임라인 위 난이도 칩 왼쪽에 칩 하나가 있고, 누르면 두 모드가
  전환됩니다. 세 번째 상태가 없으므로 칩은 항상 현재 모드를 그대로 보여 줍니다.
  - **편집**은 깔끔한 차팅 화면입니다. Sapphire 오버레이와 키 뷰어가 물러나고, 게임의 난이도 ·
    노페일 · 자동 재생 아이콘과 판정 오차 미터가 숨겨집니다. 플레이 테스트를 시작하면 자동
    재생이 켜지며, 직접 치고 싶으면 `Ctrl+E` → 기능에서 **편집 모드에서 자동 재생**을 끕니다.
  - **플레이**는 그 반대입니다. 자동 재생이 꺼지고, 노페일이 켜지며(옵션 — 끄면 미스를 그대로
    느낍니다), 타임라인을 포함한 Sapphire UI가 **음정 오버레이만 남기고** 모두 숨겨지고, 타일
    배치와 삭제가 막혀 듣고 있는 채보가 실수로 바뀌지 않습니다. 우측 상단 마스터 스위치도 함께
    숨겨지니 돌아올 때는 모드 칩이나 `Ctrl+E`를 쓰면 됩니다.

  자동 재생과 노페일은 모드를 켤 때와 플레이를 시작할 때만 적용되므로, 도중에 직접 바꾼 값은
  유지됩니다.

## 단축키 참조

| 키 | 상황 | 동작 |
|---|---|---|
| `Ctrl+E` | 어디서나 | 설정 열기 |
| `숫자` | 도구/선택 없음 | 툴바 도구 선택 |
| `숫자` | 타일 선택됨 | 독 카테고리의 n번째 이벤트 선택; `Enter`로 찍기 |
| `,` / `.` | 에디터 | 이전 도구 / 저장 슬롯 (`Shift+.`로 슬롯 저장) |
| `Shift+K` | 에디터 | 빠른 차팅 모드 토글 (툴바의 `Q` 칸과 동일합니다) |
| `Shift+F` | 에디터 | Hz 도구 토글 |
| `I` `O` `[` `]` | 빠른 차팅 | 소용돌이 / 속도 설정 / 절반 / 두 배 |
| `Shift+P` `Shift+L` `Shift+R` `Shift+O` `Shift+G` `U` | 빠른 차팅 | 일시정지 / 위치 / 타일 이동 / 홀드 / 각도 패드 / 편집 |

위의 빠른 차팅·도구 슬롯 키는 **기본값**이며, 설정 ▸ 단축키에서 다시 지정할 수
있습니다. 기본값은 게임 에디터의 타일 배치 글자 17개(`a b c d e h j m n q s t v w x y z`)를
피해서 정했습니다. 게임은 이 글자들을 `Shift` 유무 양쪽에 등록하므로, 그 글자에 지정하면
타일 배치를 빼앗습니다.
| `A` `N` | 에디터 | 자동플레이 팬 / 노페일 토글 |
| `Esc` | 팝업 | 포커스된 Sapphire 팝업 닫기 |
